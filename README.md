# Sayyam Sikander — Professional Website Redesign

Static GitHub Pages-ready website built with plain HTML, CSS and JavaScript.

## Publish on GitHub Pages

1. Replace the current repository files with the contents of this folder.
2. Keep `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`, `site.webmanifest` and the `assets/` folder in the repository root.
3. Commit and push to the branch currently used by GitHub Pages.
4. In **Settings → Pages**, confirm the correct branch/folder is selected.
5. After deployment, submit `https://sayyamnrg.github.io/b2b-b2c/sitemap.xml` to Google Search Console.

## SEO included

- Descriptive title and meta description
- Canonical URL
- Open Graph and Twitter sharing metadata
- `Person`, `ProfessionalService`, and `FAQPage` JSON-LD structured data
- `robots.txt` and `sitemap.xml`
- Semantic heading hierarchy
- Fast system fonts and no external JavaScript libraries
- Mobile-first responsive layouts
- Accessible navigation, skip link, focus support and reduced-motion support

## Before publishing

Review the phone number, LinkedIn URL, email address, service wording and public-review metrics. If any profile data changes, update the homepage and structured data to match.
